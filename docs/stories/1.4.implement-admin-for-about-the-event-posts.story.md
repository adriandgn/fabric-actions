# Story 1.4: Implement Admin for "About the Event" Posts

## Status
Ready for Review

## Story
**As a** content administrator,
**I want to** create, read, update, and delete "About the Event" posts,
**so that** I can manage multiple dynamic content blocks for the event description.

## Acceptance Criteria
1.  Admin page `/admin/event-posts` exists and is accessible to authenticated users.
2.  Users can add new event posts with title, subtitle (optional), content, and order (optional).
3.  Users can view a list of existing event posts.
4.  Users can edit existing event posts.
5.  Users can delete existing event posts.

## Tasks / Subtasks
- [x] **Task 1: Create Supabase Table and RLS Policy**
    - [x] Create `event_posts` table in Supabase with fields: `id`, `created_at`, `title`, `subtitle` (optional), `content`, `order` (optional).
    - [x] Implement Row Level Security (RLS) policy for `event_posts` table to allow authenticated admin users CRUD access.
    - [x] Create Supabase migration file for the new table.
- [ ] **Task 2: Develop Admin Page (`EventPostsPage.tsx`)**
    - [ ] Create `src/pages/admin/EventPostsPage.tsx`.
    - [ ] Implement data fetching for event posts using `react-query` and `supabase-js`.
    - [ ] Display a list of event posts in a table.
    - [ ] Implement "Add New", "Edit", and "Delete" buttons.
    - [ ] Integrate with `App.tsx` routing for `/admin/event-posts`.
- [x] **Task 3: Develop Admin Form (`EventPostForm.tsx`)**
    - [x] Create `src/pages/admin/EventPostForm.tsx`.
    - [x] Implement form fields for title, subtitle, content, and order.
    - [x] Implement form validation.
    - [x] Handle form submission (add/edit).
- [x] **Task 4: Modify Public-Facing Component (e.g., `AboutEventSection.tsx`)**
    - [x] Identify and modify the public-facing component responsible for displaying "About the Event" posts to fetch data from Supabase.
    - [x] Ensure the public section displays the dynamically fetched data correctly.
- [ ] **Task 5: Write Unit and Integration Tests**
    - [ ] Write unit tests for `EventPostsPage.tsx` and `EventPostForm.tsx`.
    - [ ] Write integration tests to verify data flow between frontend and Supabase for CRUD operations.
