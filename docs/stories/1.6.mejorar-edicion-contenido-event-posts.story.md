Title: Mejorar la edición de contenido en Event Posts (Admin)
Status: Draft
Story: |
  Como administrador,
  quiero una ventana de edición y creación de Event Posts más grande y un campo de contenido con edición HTML básica,
  para poder escribir y formatear el contenido de los posts de manera más cómoda y eficiente.
Acceptance Criteria:
  - La ventana modal de edición/creación de Event Posts en `/admin/event-posts` debe tener un tamaño visiblemente mayor que el actual, permitiendo una mejor visualización del formulario.
  - El campo "Content" dentro de la ventana de edición/creación de Event Posts debe ser un editor de texto enriquecido (WYSIWYG) que permita:
      - Aplicar formato de negrita (bold).
      - Insertar enlaces (links).
      - Insertar saltos de línea (line breaks).
      - (Opcional, si el editor lo soporta fácilmente) Otros formatos básicos como cursiva, listas.
  - El contenido HTML generado por el editor debe guardarse correctamente en la base de datos y renderizarse adecuadamente al visualizar el post.
Dev Notes:
  Contexto del Proyecto: Aplicación de una sola página (SPA) construida con React (v18) y TypeScript. Utiliza Vite, Tailwind CSS, `shadcn/ui` y React Hook Form para formularios.
  Componentes: La sección `/admin/event-posts` utiliza el componente `EventPostForm`. Actualmente, el campo `content` es un `Textarea` de `shadcn/ui`.
  Requisitos:
    Ventana Modal: La ventana modal de edición/creación de Event Posts necesita un ajuste de tamaño. Esto podría implicar modificar el componente `Dialog` de `shadcn/ui` o su contenedor.
    Editor HTML: El campo `content` requiere un editor de texto enriquecido (WYSIWYG). Esto implicará reemplazar el `Textarea` actual por un componente de editor HTML. Se deberá investigar una librería de editor de texto enriquecido compatible con React y `shadcn/ui` (ej. `react-quill`, `tiptap`, `draft-js`).
    Almacenamiento de Contenido: El campo `content` en el modelo `event_posts` es de tipo `text`, lo cual es adecuado para almacenar HTML.
  Consideraciones:
    Integración del editor de texto enriquecido con `react-hook-form` y `zod` para la validación.
    Asegurar que el HTML generado sea seguro y se renderice correctamente en la interfaz de usuario pública.
Tasks / Subtasks:
  - [ ] Aumentar el tamaño de la ventana modal de edición/creación de Event Posts en `/admin/event-posts`.
  - [ ] Investigar y seleccionar una librería de editor de texto enriquecido compatible con React y el stack actual (ej. `react-quill`, `tiptap`).
  - [ ] Implementar el editor de texto enriquecido para el campo "Content" en `EventPostForm`.
  - [ ] Integrar el editor de texto enriquecido con `react-hook-form` para la gestión del estado y la validación.
  - [ ] Asegurar que el contenido HTML se guarde correctamente en Supabase.
  - [ ] Asegurar que el contenido HTML se renderice correctamente al visualizar los Event Posts.
  - [ ] Realizar pruebas funcionales para verificar la edición, creación y visualización de contenido HTML.
